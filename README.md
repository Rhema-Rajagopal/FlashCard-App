# FlashCard-App
📚 Flashcards Study App
Project Description

The Flashcards Study App is a simple, browser-based study application built using HTML, CSS, and JavaScript.

It allows users to create flashcard decks, add questions and answers, and study using interactive flashcards. The application uses LocalStorage to save data in the browser.

Features
Create multiple flashcard decks.
Edit and delete decks.
Add, edit, and delete flashcards.
Flip flashcards to view answers.
Navigate using Previous and Next buttons.
Shuffle flashcards.
Search flashcards using keywords.
Save decks and cards using LocalStorage.
Responsive user interface.
Keyboard shortcuts for studying.
Technologies Used
HTML5 – Website structure.
CSS3 – Styling and responsive layout.
JavaScript – Application functionality.
LocalStorage – Data persistence.
AI Coding Assistant – Help with generating and improving code.
How to Run the Project
Download or clone this repository.
Open the project folder in VS Code.
Open index.html in your browser.
Create a new deck and start adding flashcards.

Reflection: Learning from AI-Assisted Development
Where AI saved time: AI helped me generate the initial HTML structure, CSS styling, and JavaScript functionality much faster than writing everything manually.
AI bug identified and fixed: Initially, the CSS styling was not displaying correctly because the stylesheet was not being applied. I checked the CSS file link in HTML and refreshed the browser to fix the issue.
Code refactoring: I organized the JavaScript into smaller functions such as renderDecks(), renderStudyCard(), saveData(), and loadData() to make the code easier to understand and maintain.
Accessibility improvement: I added accessible labels to the search input and keyboard shortcuts for flipping cards and navigating between flashcards.
Prompt improvements: Giving AI specific instructions about using vanilla JavaScript, LocalStorage, responsive CSS, and accessible HTML helped generate more useful and consistent code.
Conclusion

This project helped me understand how AI coding assistants can speed up web development. I also learned the importance of testing AI-generated code, identifying bugs, and improving the code to make the application work correctly.
